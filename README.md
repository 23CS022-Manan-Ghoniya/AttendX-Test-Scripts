# AttendX Test Scripts

## Project Description
This repository contains automation test scripts for the
AttendX student attendance application.

## Test Scripts

1. test_login.py
   Verifies login with valid student credentials.

2. test_attendance.py
   Verifies that a logged-in student can mark attendance.

## Prerequisites
- Python 3
- Git
- Google Chrome
- AttendX application running locally or at a test URL
- Selenium and pytest

## Installation
Install dependencies:

    python -m pip install selenium pytest

## Execution
Run all tests:

    python -m pytest -v

## Version Control
Git is used to track changes to test scripts.
GitHub hosts the remote repository for collaboration.
